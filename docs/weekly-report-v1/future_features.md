---

## 📋 機能アイデア一覧

### High Priority (ポートフォリオ映え)

| 機能 | 価値 | 技術的アピール |
|---|---|---|
| AI 添削・要約 | LLM で週報を整形・改善提案 | OpenAI API 連携 |
| グラフ・分析 | 作業時間の可視化・傾向分析 | Chart.js / Recharts |
| Slack/Teams 連携 | 提出忘れリマインダー・通知 | Webhook 連携 |

### Medium Priority (実用性向上)

| 機能 | 価値 | 技術的アピール |
|---|---|---|
| 週報テンプレート | 毎週同じ項目を自動生成 | DB 設計・UX |
| 過去週報コピー | 先週の続きから書ける | CRUD 応用 |
| 進捗トラッキング | 前週との差分を可視化 | データ比較ロジック |
| PDF エクスポート | 人事提出用にフォーマット出力 | サーバーサイド PDF 生成 |

### Nice to Have (将来的)

| 機能 | 価値 | 技術的アピール |
|---|---|---|
| チーム閲覧 | マネージャーが部下の週報一覧 | RLS 活用・マルチテナント |
| コメント機能 | 上司からのフィードバック | リアルタイム更新 |
| モバイル対応 PWA | スマホからサクッと提出 | PWA・Responsive |

## ⚠️ 本番デプロイ時チェックリスト

> **v1.0.0 本番リリース時に必ず対応すること**

### OAuth App URL 変更

開発用（`localhost:3000`）から本番 URL に変更が必要。

| `プロバイダー` | `設定場所` | `変更内容` |
|---|---|---|
| `GitHub` | `https://github.com/settings/developers` | `Homepage URL`, `Authorization callback URL` を本番 URL に |
| `Google` | `https://console.cloud.google.com/apis/credentials` | `承認済み JavaScript 生成元`, `承認済みリダイレクト URI` を本番 URL に |

**推奨**: 開発用と本番用で別の OAuth App を作成し、Vercel の環境変数を本番用に設定。
